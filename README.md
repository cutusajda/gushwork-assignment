# Mangalam HDPE Pipes – Premium Product Website

A modern, responsive single-page website for **Mangalam HDPE Pipes**, built as an assignment project for **Gushwork**.

---

## 🎯 Project Overview

This is a fully functional, high-fidelity product detail page for a premium HDPE Pipes & Coils manufacturer. The website showcases professional design, smooth interactions, and excellent user experience with features like image zoom, carousels, process tabs, modals, and form handling.

Despite some leftover copy from a textile machinery brand (Meera Industries), the design and functionality are complete and production-ready.

---

## ✨ Features

### Core Functionality
- **Sticky Header** with product thumbnail that appears on scroll
- **Interactive Image Gallery** with:
  - Hover-to-zoom magnifier lens
  - Side zoom preview panel
  - Thumbnail navigation
  - Previous/Next arrows
- **Responsive Carousels** (Applications & Testimonials)
- **Process Steps** with tab navigation (Desktop + Mobile)
- **FAQ Section** with accordion behavior
- **Multiple Modals** (Contact, Quote, Catalogue)
- **Toast Notifications** for form feedback
- **Smooth Scroll** & Mobile Menu

### Design & UX
- Fully responsive (Mobile, Tablet, Desktop)
- Modern clean UI with professional typography (Inter font)
- Hover animations and micro-interactions
- Dark technical specs section
- Marquee brand strip
- Form validation
- Accessibility-friendly markup


## 🛠️ Technologies Used

- **HTML5** – Semantic markup
- **CSS3** – Custom properties, Flexbox, Grid, Animations
- **Vanilla JavaScript** – No frameworks
- **Google Fonts** – Inter typeface
- **Unsplash** – Placeholder images

## 🚀 How to Run

1. Download or clone the project
2. Place all files in the same folder
3. Open `index.html` in your browser

**No build tools or server required** — works directly from the file system.
